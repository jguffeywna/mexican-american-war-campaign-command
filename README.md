# Campaign Command: Mexican–American War

This folder is ready for GitHub Pages. It contains one self-grading 100-point activity and all historical images needed to run it.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html` and the entire `assets` folder. Keep the folder name and image filenames unchanged.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then select **Save**.
6. After deployment finishes, GitHub will display the activity URL.

## Add to Canvas

Create a Canvas Assignment worth **100 points**. Add the GitHub Pages URL as an **External URL** or place it in a Canvas Page using an iframe. Students can use **Copy results summary** after finishing and paste the result into the assignment submission box.

The activity grades itself in the browser but does not send grades directly to the Canvas gradebook. Direct grade transfer would require an approved LTI integration.
